## Basic Info

This game was created for **HackYeah**.

It was developed in **2024 during a 24-hour hackathon**.

## Game Info

It is a **2D survival game** where your task is to defend the city from **fossas' cyber attacks**.

The game is really fun and worth trying.

The game can be played here:
https://steellotus.itch.io/night-of-lemur

## Technology

The game was developed using **Unity** with the **C# programming language**.
